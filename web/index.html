Der Standort-Filter gilt auch für die Spalte „Im Lager“ im Rechner. CCP aktualisiert die Asset-Daten höchstens einmal pro Stunde.

Was kann ich mit diesem Lager bauen?

1

Spieldaten laden

Lädt einmalig die Blaupausen und Itemnamen direkt von CCP (ca. 100 MB Download, dauert je nach Leitung ein paar Minuten).

2

EVE-Anwendung registrieren (einmalig)

Damit das Programm Assets, Blaupausen und Skills lesen darf, braucht es eine eigene Zugangs-ID von CCP. Das ist kostenlos und dauert zwei Minuten.

  1. Auf developers.eveonline.com/applications mit dem EVE-Account anmelden.
  2. Create new application anklicken. Name z. B. „Produktionsrechner“, Beschreibung beliebig.
  3. Bei Connection Type „Authentication & API Access“ wählen.
  4. Diese Berechtigungen (Scopes) auswählen:
  5. Als Callback URL eintragen:
  6. Speichern, dann die Client ID kopieren und hier einfügen. Das Secret wird nicht gebraucht.
3

Charakter anmelden
